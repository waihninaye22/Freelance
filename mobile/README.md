# Archer Mobile

The Expo React Native mobile app is planned but has not been scaffolded yet. It will be an independent project in this monorepo, with its own dependencies, environment, build, and release process.

The mobile client will use the versioned HTTP API described in [`../api/openapi.yaml`](../api/openapi.yaml). It must not connect directly to the API's SQLite database. Product behavior and supported features are defined in [`../SPEC.md`](../SPEC.md).
